# Release files

Each release uses a reviewed `release.json` and `notes.md` in its own directory.
The declaration includes a version tag and a concise headline. The release
title is `<tag>: <headline>`, while authored notes begin with the highlights.
See [the release guide](../docs/releasing.md) for the supported formats,
independent version streams, candidate preparation, and publication approval.
Engine builds publish a standalone wheel and a verified installation ZIP, with
a detached attestation for each subject.

This directory contains no active release request until a declaration is added.
